# ArthSetu

A JavaFX-based Banking Management System built to simulate core banking operations such as customer management, account creation, fund transfers, deposits, withdrawals, and transaction tracking.

## Features

- Admin Login
- Customer Login
- Account Management
- Deposits & Withdrawals
- Fund Transfers
- Transaction History

## Tech Stack

- Java 21
- JavaFX
- Maven
- JDBC

## Run

```bash
mvn clean javafx:run
```
